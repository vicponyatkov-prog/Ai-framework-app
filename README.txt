AI FRAMEWORK — мини-приложение для Android, iPhone и ПК

В ПАПКЕ:
- index.html — страница приложения
- styles.css / app.js — оформление и логика
- manifest.webmanifest — имя приложения и иконка
- sw.js — работа офлайн после первого посещения сайта
- icons/ — две иконки

БЫСТРЫЙ ПРОСМОТР:
Открой index.html в браузере. Карточки, поиск и копирование будут работать даже без сервера. Однако такой просмотр не гарантирует установку в виде отдельного приложения.

КАК ПОЛУЧИТЬ ЯРЛЫК НА ANDROID:
1) Опубликуй папку как статический HTTPS-сайт (например, через GitHub Pages или Netlify).
2) Открой полученный HTTPS-адрес в Google Chrome на Android.
3) Нажми ⋮ → «Установить приложение» или «Добавить на главный экран» (пункт зависит от версии Chrome).
4) Подтверди установку. Появится ярлык «AI Framework» с собственной иконкой.
5) Открой один раз онлайн. Далее содержимое может работать офлайн благодаря service worker.

ВАЖНО:
- В режиме открытия файла file:// установка PWA и кеширование service worker не работают.
- Сервису публикации нужны HTTPS и раздача всех файлов папки с сохранением структуры.
- Ни одна показанная в исходнике мета-команда не имеет системных привилегий в ChatGPT.
- Данные «Избранного» сохраняются локально; при очистке данных приложения могут исчезнуть.
